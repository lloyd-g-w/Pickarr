Rules & Preferences

Hard rules determine what Pickarr is allowed to choose.

Structured preferences influence scoring predictably.

Natural language preferences let the AI understand more nuanced instructions.

Priority order
  1. Sonarr/Radarr hard rejection
  2. Pickarr hard rules
  3. Explicit structured preferences
  4. Natural language preferences
  5. Deterministic scoring
  6. General default AI preferences

Natural language preferences are soft: they can never override a hard rule. If you ask for AV1 but AV1 is in the blocked codec list, AV1 is still rejected.

Natural language preferences

Describe what you want in plain English. This text is sent to the model every time it ranks releases, together with the metadata of the item being evaluated, so conditional instructions ("for TV shows…", "for 4K…") are applied only where they are relevant.

Hard rules

Deterministic. A release that violates any of these is rejected and can never be chosen.

Structured preferences

Soft. These shift the deterministic score in a predictable way.

Scoring weights

Points added (or removed) by each scoring component.

Sonarr & Radarr instances

Multiple instances of each application are supported. Per-instance natural language preferences are appended to the global ones for selections on that instance.

AI settings

Any OpenAI-compatible /chat/completions endpoint works, including local servers such as llama.cpp, Ollama or vLLM.

Automatic mode

Pickarr polls each instance that has automatic enabled for wanted items, runs the pipeline and grabs the winner. Leave grab off first: passes are then dry runs that only log what would have been grabbed.

General & Security

Account

API key

Send it as X-Api-Key, or as ?apikey= in a URL. Sonarr/Radarr webhooks need the query form: http://pickarr:8484/api/webhook/<instance_id>?apikey=<key>
Seerr / Overseerr / Jellyseerr: webhook URL http://pickarr:8484/api/webhook/seerr with the API key as the Authorization Header (default JSON payload).

Authentication required

Disabling this leaves Pickarr open to anyone who can reach the port, exactly like turning off authentication in Sonarr/Radarr. The login page stays available.
